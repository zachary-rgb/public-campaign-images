## Changes Made (Technical)

### Window:
```python
# Before
geometry("850x600")

# After
geometry("820x550")  # 50px shorter
```

### Padding:
```python
# Before
padding=5-10, pady=5

# After  
padding=3, pady=2-3  # More compact
```

### Fonts:
```python
# Before
font=("Arial", 9-14)

# After
font=("Arial", 8-12)  # Slightly smaller, still readable
```

### Output Log:
```python
# Before
height=10  # 10 lines

# After
height=8  # 8 lines, saves 25px
```
