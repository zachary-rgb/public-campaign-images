+To receive status back from Portamedic on API orders the client must provide a webhook.  The webhook should be able to receive ClinicalCase Json in the body of a POST. Currently we support bearer authentication (Optional), via a static token or an OAuth2 service. If the client decides to secure their webhook they will provide the token or OAuth2 URL, secret, and id.
