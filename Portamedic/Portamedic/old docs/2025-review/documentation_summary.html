🔔 Status Process & WebHook NEW in v2

To receive status updates from Portamedic on API orders, clients must provide a webhook endpoint.

WebHook Requirements

Method: POST
Body: ClinicalCase JSON
Auth: Bearer token (optional) or OAuth2

If securing the webhook, provide: token OR OAuth2 URL + secret + id

Status Lifecycle

ENTERED → READY_FOR_APPOINTMENT → SERVICES_COMPLETE → COMPLETED
or CANCELLED

Event Codes

INFO

Appointment set, case accepted

CONTACT

Released to examiner

SCHEDULED

Appointment confirmed

IMAGED

Case image available

New Response Fields

smsOptIn emailOptIn KitBarCode TrackingNumber CaseExtras AppsLinkCode SentToOriginator

⚠️ Common API Errors (Schedule4Real)

Error Description
strUserName cannot be blank Username is required
The user is invalid Username/password not found in database
strAccountNumber must be 5 chars Account number format is invalid
intAge is invalid, < 1 or > 120 Age must be between 1 and 120
intAmount is invalid Insurance amount must be 0-50,000,000
strZipCode must be 5 digits Zip code format is invalid
datReservation must be 5 days out Reservation date is too soon
No examiners can cover this scenario No coverage for zip with required equipment
strUniqueID already exists Unique ID must be unique in the database
