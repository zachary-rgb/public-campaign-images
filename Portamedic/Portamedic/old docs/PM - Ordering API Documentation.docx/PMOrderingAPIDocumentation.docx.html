Submitting a New Case

Calling the new case Restful service is a two-step process.

  1. Retrieve an OAuth2 token from the token service.
  2. Post order data in JSON (see JSON schema) format to API with the token (previous step).  

You must call the authentication API with your credentials (Supplied by Portamedic) for a token.  The token must then be passed with your subsequent orders to the new order API.  The token typically expires in 5 minutes; you can request a new token with each call or use the token until it expires and request a new one.

Calling the Token Service

The following curl call can be used to demonstrate the token service, client_id and client_secret will be provided by Portamedic:

curl -d “grant_type=client_credentials&client_id=CLIENTID&client_secret=CLIENTSECRET" https://auth.integratedtestingservices.com:8020/TokenService/connect/token

Verb: Post

Body: grant_type=client_credentials&client_id=CLIENTID&client_secret=CLIENTSECRET

Response Codes

200 Success

401 Authentication error

400 Bad Request

Response Body:        

{  

  "access_token": "eyJhJdLCJjbGllbnRfaWQiOiJiMWFhZTZiZS1iNThiLTR.........TBQe_BmQ",

  "expires_in": 300,

  "token_type": "Bearer",

  "scope": "Clinical.Originator"

}
