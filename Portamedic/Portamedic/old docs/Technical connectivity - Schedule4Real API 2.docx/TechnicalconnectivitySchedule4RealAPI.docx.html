Process Requirements

The carrier will pass the below parameters via Web Service for APPS to return availability.  APPS will provide a list of date and time available to schedule and include the examiner ID #.  Upon selection, in the event if the user “times out” or the selected appointment is no longer available, APPS will pass back a message to the carrier.

Parameters needed:

Zip code        = 5-character code

Gender                = M/F – will also accept Male/Female but will only look at fist letters

Unique ID         = OrderNo or Policy# can be used (to be determined by carrier)

Account #        = CompanyID

Requirements        = 'BLOOD','EKG','URINE','VITALS'

Reservation date = MM/DD/YYYY

Security
